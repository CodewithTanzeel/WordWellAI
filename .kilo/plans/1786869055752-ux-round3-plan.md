## T7 — Error-handling resilience

**Goal:** Prevent crashes from unavailable browser APIs and uncaught storage errors.

### T7a — `getDeviceId()` UUID fallback
- `frontend/App.tsx` — `crypto.randomUUID()` is unavailable in older Safari/Firefox. Wrap in try/catch; on failure, fall back to `Date.now().toString(36) + Math.random().toString(36).slice(2)`.

### T7b — `localStorage` read/write guards
- `frontend/App.tsx` — `lastCheckIn` read and `sift-last-checkin` write already have `typeof window !== "undefined"` checks. Wrap `localStorage.setItem` in try/catch to handle private-browsing quota errors gracefully (silent fail, no crash).

**Validation:** `npx vitest run` passes. Simulate `crypto.randomUUID = undefined` in a test — app still renders.
